# 咕咕骑车 Coucou Bike

官网 [coucoubike.com](https://coucoubike.com) · 隐私政策 [不收集任何数据](https://coucoubike.com/privacy.html)

看得见成长的 iPhone 骑行数据展示 App。

主流运动 App 开始往语音播报里塞广告，苹果自带的体能训练能记数据却没有一个好看的全景视图。咕咕骑车只做一件事：把你的骑行数据摆清楚，让你看见自己的成长。

- 第一个 tab「骑行数据」：忠实记录。总里程与保养提醒、骑行日历热力图、日/周/月里程柱状图、逐条骑行历史（可导出 Markdown）
- 第二个 tab「个人纪录」：用数据激励。最长单次、最快均速、最快 5 公里、最快 1 公里、单月最多，以及和过去的自己比（本周对上周、本月对上月、今年对去年同期）

## 原则

1. **只读健康** · 记录交给手表和 iPhone（HealthKit），咕咕只负责读出来、摆清楚，绝不写入一个字节
2. **专注展示** · 不做码表，不做社交，把一件事做好：让你看清自己的骑行数据
3. **数据永不丢失** · 原始记录都在苹果健康里，咕咕自己不存原始数据，删掉缓存也只是重新算一遍
4. **无广告，永久** · 不卖货，不打广告，不搞歪门邪道
5. **开源，仅限自用** · 代码公开，欢迎学习和自建。仅限非商业用途，与本仓库商店发行版互不冲突
6. **不发明 UI** · 能用苹果就苹果：日历像日历，图表像图表，不重新发明系统已经做好的东西
7. **不算不编** · 苹果健康里没有的数据就不写、不计算，绝不编一个数字给你看

## 为什么叫 Coucou

布谷鸟是最古老的提醒器：黑森林的布谷鸟钟每整点跳出来报一次时；在中国民间，它的叫声"布谷"就是"播谷"，提醒农人下地；在法语里，coucou 既是布谷鸟的叫声，也是熟人之间那句轻快的"嗨～"。

陪你骑车、帮你记住每一次进步的 App，和它属于同一个物种。中文叫**咕咕骑车**（咕咕，是布谷鸟的叫声）。

## 开发流程：冒烟测试与发版关卡

运动软件要求严谨。测试分两档：

- **日常开发**：`./scripts/smoke.sh`，改动涉及时随时跑，不拦推送（跑完约 2 分钟）
- **正式发版（强制）**：`./scripts/release.sh`，全量冒烟 + 真机编译装机 + 人工实测清单，逐项打勾后才能提审/发布

重要测试 case 统一登记在 [SMOKE.md](SMOKE.md)（每条对应一次真实事故），事故复盘后先补 case 再修车。
